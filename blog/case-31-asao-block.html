【施工事例31】小さなシミがブロック解体まで発展

川崎市麻生区A様｜築27年｜コーキング劣化の放置が招いた大規模修理

施工概要

地域

川崎市麻生区A様

築年数

築27年

症状

雨漏り（サイディング腐食・ブロック劣化）

工期

7日間

施工費用（税込）

90万円

大規模修理（サイディング張り替え・ブロック新設・コーキング）

💰 火災保険適用の可能性

台風・強風による外壁損傷の場合、火災保険の風災補償で修理できる場合があります。当社が申請サポートいたします。

症状と原因

発見時の症状

  • 窓下の外壁に小さなシミが発生
  • 「少しのシミだから大丈夫」と放置
  • 数年後、サイディングがブヨブヨに腐食
  • 点検の結果、ブロック解体が必要な状態まで悪化

原因

コーキング（シーリング）の劣化を放置したことが原因です。

  1. 窓枠周辺のコーキングが劣化し、ひび割れ・剥がれが発生
  2. 隙間から雨水が年々浸入し、サイディング裏側に蓄積
  3. サイディング内部で腐食が進行（外からは見えない）
  4. 下地木材・ブロックまで水が到達し、構造体が劣化
  5. 気づいたときには大規模修理が必要な状態に

教訓

「小さなシミだから大丈夫」は危険信号！コーキングの劣化は築10年で点検・15年で打ち替えが基本です。放置すると修理費用が10倍以上に膨らむケースも。

施工内容

1. 既存サイディング撤去

  • 腐食したサイディングパネルを全面撤去
  • 下地木材の状態を確認し、腐食部分を交換

2. ブロック解体・新設

  • 狭い場所での難工事：隣家との隙間が狭く、重機が入らない
  • 手作業で既存ブロックを解体
  • 基礎コンクリートを補修後、新しいブロックを積み直し
  • 防水モルタルでしっかり仕上げ

3. 新規サイディング張り

  • 防水シートを新規施工
  • 高耐久サイディングを採用（15年保証品）
  • 通気工法で湿気対策を徹底

4. コーキング打ち替え

  • 窓枠・サイディング目地の既存コーキングを完全撤去
  • 高耐久シーリング材（変成シリコン）で打ち替え
  • 全周しっかり充填し、再発防止

施工写真

施工後：窓下サイディング張り替え完了

施工中：ブロック解体状況（腐食部分を撤去）

施工前：サイディング下部の劣化状態

施工中：ブロック新設工事（モルタル充填）

施工中：新規サイディング張り付け作業

施工完了：真っ白な外壁に生まれ変わり
