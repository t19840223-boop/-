【設定手順】
━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 除外キーワード設定
1. Google広告管理画面を開く
2. 左メニュー → キーワード → 除外キーワード
3. 「+」ボタンをクリック
4. ファイルの内容をコピペして保存

■ ターゲットキーワード追加
1. Google広告管理画面を開く
2. 左メニュー → キーワード → 「+ キーワードを追加」
3. マッチタイプを選択
   - STEP 3-14: フレーズ一致
   - STEP 15: 完全一致
4. ファイルの内容をコピペして保存
