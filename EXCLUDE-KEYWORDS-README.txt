## ⚡ 簡単3ステップ（5分）

### ステップ1: ファイルを開く
```
ファイル名: google-ads-exclude-keywords-complete.txt
場所: /home/user/webapp/
```

### ステップ2: 全選択してコピー
1. ファイルを開く
2. **Ctrl+A（全選択）**
3. **Ctrl+C（コピー）**

### ステップ3: Google広告に貼り付け
1. Google広告管理画面にログイン
2. 左メニュー「キーワード」→「除外キーワード」
3. 「＋」ボタンをクリック
4. **Ctrl+V（貼り付け）**
5. **マッチタイプ**: 「部分一致」を選択
6. 「保存」をクリック
